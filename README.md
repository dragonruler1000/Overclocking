# Overclocking
A factorio mod that adds an overclocking module, cooling towers, and a new ore

future updates will be uploaded here: https://mods.factorio.com/mod/Overclocking

Overclocking adds cryolite a new resource that can be used to make overclocking modules which are modules that give speed and productivity bonuses and a overclocking tower which is a beacon that you can put the overclocking module in that requires a new fluid called coolent to run.
here is a video showing off the new features added in: https://youtu.be/SLe4BCPYdjM
